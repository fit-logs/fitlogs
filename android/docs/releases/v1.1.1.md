# FitLogs 1.1.1

The Android app now lives in [fit-logs/fitlogs](https://github.com/fit-logs/fitlogs). This release combines the published workout-library and session features with the latest local running, progress, body-profile, backup and updater work.

Download **fitnotes.apk** and install it over the existing FitNotes application. Keep the app installed and retain its data. The package and signing certificate are unchanged. Version code 4 updates both local 1.1 (2) and the legacy beta builds.

The old updater cannot discover this repository transition automatically. Install this release manually once; afterward **Settings → Update app** checks this repository's stable releases. Android still asks for installation permission and confirmation.

This release includes the updater manifest and checksums, a corresponding-source archive, and an independent JSON workout catalog. It no longer depends on the legacy webapp. Database migration converges the released and local-development schemas while retaining recorded training, body profiles and running associations.

The legacy repository retains its old releases for reference. New Android development and releases belong here.
