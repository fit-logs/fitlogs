# FitLogs 1.1.3

- Create a training dashboard in your own Google Drive from Settings.
- Sync completed workouts and imported history into native Google Sheets charts.
- Choose whether to include notes and body measurements; both start excluded.
- Optionally refresh the same dashboard after local changes, once workouts finish.
- Keep photos, raw heart-rate samples, credentials and developer accounts out of the dashboard.
- Preserve offline logging, local backups, the existing Android package and signing certificate.

Google authorization is available to all users. Each phone must approve its own
account access. Real-device Google consent and sync still need verification;
the dashboard is an optional copy, not a recoverable full backup.
