Log a workout directly from the day it happened.

- Open a workout, use the date arrows or picker to choose a previous day, then tap **Log workout for this day**. The entry form starts on that date, including days that already contain a session.
- Empty dates stay open when browsing from Train, so you can add the missing session.
- **Train → Log past workout** and **History → Log past workout** still default to yesterday. Enter the sets you performed, then tap **Save completed**.
- Train keeps **Log past workout** directly below **Start empty workout / Resume workout**, ahead of live timer controls.
- Past entries keep your live workout running separately. Copying a workout supplies exercise references; performed sets are entered explicitly.

## Install

Download **fitnotes-1.0.0-beta.2.apk** and open it on your Android phone. Android 7.0 or later is required. Export a backup first, including photos if desired, then install as an update. Keep the installed app and its data if Android reports a signature mismatch.

Package `com.example.fitnotes`, version code **3**. Update compatibility requires the same signing certificate as beta.1: `7ab64af6c9ab261ba03a9471b6a3adc59fa33d684d5d1c4ef1f06a6bc693ddce`. Database version 15, training backup version 13, and analysis JSON version 6 are unchanged.

`SHA256SUMS` identifies the downloadable APK bytes. This beta is distributed through GitHub Releases.
