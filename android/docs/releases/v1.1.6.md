# FitLogs 1.1.6

## Coach

- Open the new **Coach** tab to plan your next workout or training week, review progress, or ask a custom question. Choose Gym, Running or Both and the history period to share.
- **Copy coach prompt** includes completed training and your saved goals and preferences. **View shared data** previews the exact text; private notes, body measurements, photos and raw heart-rate samples stay out of the prompt.
- Paste the prompt into your preferred AI app, then return to **Paste AI response**. Preview and edit a single workout or a strength, running or mixed program before importing. Ordinary advice is displayed without creating a workout.
- Import ordinary JSON, including fenced JSON with an explanation around it. Exercise matches require review when ambiguous. AI weight targets remain separate from the local history-based load recommendations and actual logged results.

## Flexible training queue

- **Train** shows one **Up Next** session. **Do later** moves it to the end without skipping or completing it.
- **Choose another** or **View / Edit Program** opens the full queue. Move sessions earlier/later/to the end, edit individual sessions, change optional dates, skip and restore, or start any pending strength session out of order.
- Finishing a linked strength workout completes the correct planned occurrence. Earlier pending sessions remain in the queue; active workouts can be resumed across app restarts.
- Running prescriptions support distance, duration, effort, pace and interval guidance. Link a completed recorded run from local activity records or existing Health Connect/Strava imports; importing a prescription never creates actual running results.
- Existing programs keep their completion behavior until **Enable flexible queue** is selected. Queue order, dates, status and session edits persist in training backups.

## Install and try it

Download **fitnotes.apk** from this release and open it on your phone to update the existing app. The application ID and signing certificate are unchanged. Keep the installed app and its data; exporting a current training backup before updating is recommended.

Try **Coach → Plan my training week → Both → Copy coach prompt**. Import the AI response, then try **Do later**, **Edit session** and **Start now** in the program queue.

The non-destructive database upgrade preserves existing training data, saved programs and history. Training backups use version 15; analysis exports remain version 6 and contain actual training only. No embedded chatbot, AI API key or automatic AI request is added. Reordering uses move controls, and running intervals are editable guidance text.
